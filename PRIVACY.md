# Privacy Policy – Preset Manager

*Deutsch weiter unten.*

Last updated: 19 November 2026

Preset Manager does not collect, store or send any personal data. It has no
account, no analytics, no advertising and no telemetry.

- **What the app reads and changes:** only files on your own computer – the
  presets and profiles in the Camera Raw folders, and the folders or ZIP files
  you choose for import or export.
- **What the app keeps:** its settings, backups of replaced files, an undo
  log and log files, all on your computer in `%APPDATA%\PresetManager` and
  `%LOCALAPPDATA%\PresetManager`. Log files contain file paths and error
  messages for troubleshooting; they never leave your computer unless you
  send them yourself. Only the last seven days are kept.
- **Network:** the Microsoft Store version makes no network connections at
  all; updates come from the Store. The version from GitHub asks GitHub
  (github.com) for new versions, which transmits the usual technical data
  of a web request (such as your IP address) to GitHub. See
  [GitHub's privacy statement](https://docs.github.com/site-policy/privacy-policies/github-general-privacy-statement).

Questions: please open an
[issue on GitHub](https://github.com/suebi76/preset-manager/issues).

# Datenschutzerklärung – Preset Manager

Stand: 19. November 2026

Preset Manager erhebt, speichert und sendet keine personenbezogenen Daten. Es
gibt kein Konto, keine Statistik, keine Werbung und keine Telemetrie.

- **Was die App liest und ändert:** nur Dateien auf deinem Computer – die
  Presets und Profile in den Camera-Raw-Ordnern sowie die Ordner oder
  ZIP-Dateien, die du zum Importieren oder Exportieren auswählst.
- **Was die App aufbewahrt:** ihre Einstellungen, Sicherungen ersetzter
  Dateien, ein Protokoll für Rückgängig und Logdateien, alles auf deinem
  Computer unter `%APPDATA%\PresetManager` und `%LOCALAPPDATA%\PresetManager`.
  Logdateien enthalten Dateipfade und Fehlermeldungen für die Fehlersuche;
  sie verlassen deinen Computer nur, wenn du sie selbst weitergibst. Es
  bleiben nur die der letzten sieben Tage.
- **Netz:** Die Fassung aus dem Microsoft Store baut keinerlei
  Netzverbindung auf; Updates kommen über den Store. Die Fassung von GitHub
  fragt bei GitHub (github.com) nach neuen Versionen; dabei gehen die
  üblichen technischen Daten einer Webanfrage (etwa die IP-Adresse) an
  GitHub. Siehe die
  [Datenschutzerklärung von GitHub](https://docs.github.com/site-policy/privacy-policies/github-general-privacy-statement).

Fragen: gern als
[Issue auf GitHub](https://github.com/suebi76/preset-manager/issues).
